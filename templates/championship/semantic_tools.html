🔄 RDF Reification rdf:Statement

Standard RDF reification wraps an existing triple inside an rdf:Statement resource, allowing metadata to be attached to the triple itself — not just to the subject or object. Here each f1:wonChampionship triple is reified with the driver's final championship points by a SPIN rule (reify_wonChampionship), producing a stable URI of the form stmt/champ/{driverId}/{year}.

PREFIX f1: <http://example.org/f1/> PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> SELECT ?stmt ?driverLabel ?yr ?pts WHERE { ?stmt rdf:type rdf:Statement ; rdf:predicate f1:wonChampionship ; rdf:subject ?driver ; rdf:object ?season ; f1:finalPoints ?pts . ?driver rdfs:label ?driverLabel . ?season f1:year ?yr . } ORDER BY DESC(?yr) LIMIT 20
